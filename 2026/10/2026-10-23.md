## 今日结论

1. **Agent 的“快决策层”正在产品化。** Decisions API 把结构化、低成本判断独立出来；关注理由是它会直接影响 agent 的延迟、成本与执行风险，必须配套置信度和人工回退。
2. **企业部署已进入权限治理阶段。** Uber 全员部署与 GitHub 默认策略生效都表明，连接器、默认开关和管理员控制比单纯模型选型更容易改变真实暴露面。
3. **多云分发扩大选择，也扩大责任边界。** Model Garden 与网关一致标准同步出现；关注理由是模型路由、地区处理、审计日志和安全执行不能再由单一供应商假定承担。
