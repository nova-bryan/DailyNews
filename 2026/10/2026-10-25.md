## 今日结论

1. **Agent 的控制面正从“能不能做”转为“谁在何时以何权限做”。** OpenShell、Teams 到 PR 的工作流与 Copilot 默认策略同时说明，运行时策略、审批与审计应先于扩展 agent 能力。
2. **可观测性开始覆盖真实的多工具工作流。** GitHub 把客户端、skills、agents 与 MCP 的使用展开后，团队可以治理采用和成本；但遥测低估与字段语义要求避免把看板当账单。
3. **小模型与全双工语音在推动更靠近终端的 AI。** 本地 4GB agent 模型和语音交互进展会带来更低延迟，同时也让设备权限、录音同意和身份安全成为交付前置条件。
